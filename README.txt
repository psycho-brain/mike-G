三毛猫の気まぐれクジ — 起動方法

1. ZIPを展開します。
2. index.html と assets フォルダを同じ場所に置いたまま、index.html をブラウザで開きます。
3. 管理画面のパスワードは依頼内容に合わせて設定済みです。
4. アイテム・設定・履歴は、そのブラウザの localStorage に保存されます。

重要な注意
- これは静的HTMLの試作版です。管理パスワードのSHA-256ハッシュを使い、平文パスワードはソースに書いていませんが、認証処理自体がブラウザ内にあるため、本格的なセキュリティにはなりません。複数端末で共有したり、利用者に管理画面を絶対に見せない運用には、サーバー側認証・データベースが必要です。
- 保存データは同じブラウザ・同じ端末内に限られます。ブラウザデータ削除で失われる可能性があります。
- 「1日1回」の制限もブラウザ内保存なので、別ブラウザや保存データの消去で回避され得ます。
- アイテム画像はブラウザ内に保存されます。大きな画像は1.5MB以下にしてください。
